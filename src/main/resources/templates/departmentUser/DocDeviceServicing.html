Overview

এই পেজে আপনি ডিপার্টমেন্টের Service Request—এর লিস্ট দেখবেন, যেটি তৈরি হয় Device List থেকে Service বাটনে ক্লিক করে। রিকোয়েস্ট সাবমিট হলে সেটি এখানে প্রদর্শিত হয়; পরবর্তী ধাপে CustomerCare রিভিউ/ডেলিভারি দেয়, আর ডিপার্টমেন্ট ✔ Receive দিয়ে ডিভাইস রিসিভ কনফার্ম করে।

ভিডিও: Device Servicing Module Overview Download
ওয়ার্কফ্লো এক নজরে
  1. Device List → Service → Problems + Comment দিয়ে রিকোয়েস্ট সাবমিট।
  2. Service Request List–এ রেকর্ড দেখা যাবে (কলাম: Department, Category, Problems, Device Information 👁, Request Status, CustomerCare to Dept Status, Device Sending Date, Tracking ইত্যাদি)।
  3. CustomerCare Accepted করলে ডেলিভারি শুরু হয়; স্ট্যাটাস: Device delivered।
  4. ডিপার্টমেন্ট ✔ Receive চাপলে Device received হয় এবং ট্র্যাকিং আপডেট হয়।
  5. প্রয়োজনে (Accepted নয় এমন রিকোয়েস্ট) Delete করা যাবে।
দ্রুত টিপস
  • Service Request তৈরি সবসময় Device List থেকে করুন—এখানে কেবল ম্যানেজ/রিসিভ/ডিলিট।
  • ✔ Receive কেবল তখনই দেখা যাবে, যখন CustomerCare to Dept Status = Device delivered এবং এখনও রিসিভ হয়নি।
  • Accepted রিকোয়েস্ট সাধারণত ডিলিট করা যায় না—নীতিমালা সাপেক্ষে বাটন হাইড থাকে।
  • দ্রুত খুঁজতে ডানপাশের Search ব্যবহার করুন; টেবিল হেডারের ⇅ আইকনে সোর্ট করুন; বামপাশের Page Size দিয়ে প্রতি পেজে আইটেম নিয়ন্ত্রণ করুন।
  • ডাবল ক্লিক এড়িয়ে চলুন—Save/Receive/Delete একবারই ক্লিক করুন, নইলে ডুপ্লিকেট/রেস কন্ডিশন হতে পারে।

Delete Service Request

Steps
  1. Service Request List থেকে সার্চ/সোর্ট করে টার্গেট রিকোয়েস্টটি খুঁজে নিন।
  2. নিশ্চিত হন যে Request Status Accepted নয়—Accepted হলে ডিলিট বাটন দেখাবে না।
  3. Action কলামের Delete আইকনে ক্লিক করুন।
  4. কনফার্মেশন ডায়ালগে Delete/Yes চাপুন।
  5. সাকসেস মেসেজের পর তালিকায় আইটেমটি আর আছে কি না যাচাই করুন; না থাকলে ডিলিট সফল হয়েছে।
Tips
  • Accepted স্ট্যাটাসে সাধারণত Delete লুকানো/নিষ্ক্রিয়—এ সময় ডিলিট করা যায় না।
  • ডিলিটের আগে Problems ও Device Information (👁 View) দেখে নিন—প্রসেসে থাকলে ডিলিট না করাই ভালো।
  • ডিলিট permanent; পুনরুদ্ধার সম্ভব নয়—প্রয়োজনে আগে তথ্য ব্যাকআপ নিন।
  • একবারই Delete চাপুন—ডাবল-ক্লিক/বারবার ক্লিক করলে অপ্রত্যাশিত আচরণ হতে পারে।
  • বড় তালিকায় দ্রুত খুঁজতে Search বক্স ও কলাম ⇅ সোর্ট ব্যবহার করুন।
  • ডিপার্টমেন্ট/রোল ভিত্তিক পারমিশন লাগতে পারে—বাটন না দেখালে অনুমতি যাচাই করুন।

✔ Receive Service Device

Steps
  1. Service Request List থেকে সার্চ/সোর্ট করে রিকোয়েস্টটি খুঁজে নিন।
  2. শর্ত মিলছে কি না যাচাই করুন:
    • Request Status = Accepted (বা প্রযোজ্য)
    • CustomerCare to Dept Status = Device delivered
    • Dept Receive (কলামে) ≠ Device received
  3. প্রয়োজনে Device Information কলামের View 👁 বাটনে ডিভাইসের বিস্তারিত দেখুন।
  4. Action কলামের ✔ Receive বাটনে ক্লিক করুন।
  5. কনফার্ম ডায়ালগে সম্মতি দিন—সিস্টেম রিকোয়েস্টটিকে Device received হিসেবে মার্ক করবে।
  6. তালিকায় Dept Receive কলাম আপডেট হয়েছে কি না যাচাই করুন; প্রয়োজনে Tracking → View থেকে অডিট/প্রগ্রেস দেখুন।
Tips
  • ✔ Receive বাটন শুধুমাত্র তখনই দেখা যাবে যখন স্ট্যাটাস Device delivered এবং এখনও Device received হয়নি।
  • রিসিভ করার আগে View 👁 দিয়ে ডিভাইসের স্পেসিফিকেশন/সমস্যার তালিকা (Problems) যাচাই করুন।
  • একবারই ✔ Receive ক্লিক করুন—ডাবল-ক্লিক করলে ডুপ্লিকেট/রেস কন্ডিশন হতে পারে।
  • রিসিভের পর কলামগুলো ইমিডিয়েটলি রিফ্রেশ নাও হতে পারে—প্রয়োজনে পেজ রিফ্রেশ করুন বা Tracking থেকে স্টেট দেখুন।
  • ফিজিক্যাল হ্যান্ডওভার হলে তারিখ ও ডকুমেন্ট নম্বর (যদি থাকে) নোট করুন—Device Sending Date এর সাথে মিলিয়ে রাখলে ট্রেসিং সহজ হয়।
  • বড় তালিকায় দ্রুত খুঁজতে Search বক্স ও কলাম ⇅ সোর্ট ব্যবহার করুন।
