Overview

এই পেজ থেকে আপনার ডিপার্টমেন্টের ডিভাইস ইনভেন্টরি ম্যানেজ করবেন—ডিভাইস যুক্ত করা, সম্পাদনা, সার্ভিস রিকোয়েস্ট তৈরি, ইউজারের কাছে ডিভাইস বিতরণ ও প্রয়োজন হলে ডিলিট। ডানদিকে Search এবং টেবিল হেডারের ⇅ দিয়ে দ্রুত খোঁজা/সাজানো যায়; বামদিকে Page Size দিয়ে প্রতি পেজে আইটেম সংখ্যা নিয়ন্ত্রণ করুন।

ভিডিও: Device List Module Overview Download
আপনি যা করতে পারবেন
  • ➕ Add Old Device: ক্যাটাগরি/তারিখ/ইউজার দিয়ে পুরোনো ডিভাইস যুক্ত করুন (মডাল ওপেন)।
  • Edit Old Device: নির্বাচিত ডিভাইসের তথ্য আপডেট করুন।
  • Add Service Request: সমস্যার তালিকা ও মন্তব্য দিয়ে সার্ভিস রিকোয়েস্ট পাঠান।
  • ✔ Distribute Device: ডিভাইস নির্দিষ্ট ইউজারের কাছে বরাদ্দ করুন (শুরুর তারিখসহ)।
  • Delete: প্রয়োজন হলে ডিভাইস রেকর্ড মুছুন (নীতিমালা সাপেক্ষে)।
  • 👁 View: কম্পোনেন্ট/ইউজার ইতিহাস ও ট্র্যাকিং ডিটেইলস দেখুন।
দ্রুত টিপস
  • Add Old Device–এ Category, Date, User বাধ্যতামূলক। ড্রপডাউন থেকে আইটেমে ক্লিক করে সিলেক্ট করুন।
  • সার্ভিস রিকোয়েস্টে Add Problem বা Enter দিয়ে একাধিক সমস্যা যুক্ত করা যায়; ভুল হলে X চাপুন।
  • একশন বাটন: Edit, Service, ✔ Distribute, Delete।
  • ডুপ্লিকেট এড়াতে Save একবারই ক্লিক করুন; সমস্যা হলে কনসোলে এরর দেখুন/পেজ রিফ্রেশ করুন।

Add Old Device

Steps
  1. উপরে Add Old Device বাটনে ক্লিক করুন—Add Old Device Information মডাল ওপেন হবে।
  2. Category Name ইনপুটে ক্লিক করে ড্রপডাউন থেকে সঠিক ক্যাটাগরি সিলেক্ট করুন (টাইপ করে ফিল্টার করা যায়; লিস্ট আসে সিস্টেমের categories থেকে)।
  3. Using starting Date এ ডিভাইস ব্যবহারের শুরুর তারিখ–সময় দিন (datetime-local)।
  4. User Name ইনপুটে ক্লিক করে ড্রপডাউন থেকে ইউজার নির্বাচন করুন (লিস্টে আপনার ব্রাঞ্চ/ডিপার্টমেন্টের ইউজারই দেখাবে)।
  5. Device Type হিসেবে Primary বা Secondary নির্বাচন করুন।
  6. নিচের সেকশনে ক্যাটাগরি অনুযায়ী যে dynamic fields (from universalColumns) দেখা যাবে, সেগুলো পূরণ করুন—যেমন text, number, date, file, checkbox, radio ইত্যাদি। যদি customDropDownList থাকে, সেটা লোড হতে এক মুহূর্ত সময় লাগতে পারে।
  7. সব ঠিক থাকলে Save ক্লিক করুন। (Mandatory: Category, Date, User—না থাকলে “Please Insert mandatory field (Category, Date, User)” বার্তা দেখাবে)।
  8. সাকসেস অ্যালার্টের পর মূল তালিকায় নতুন রেকর্ড এসেছে কি না যাচাই করুন (সার্চ/সোর্ট দিয়ে দ্রুত চেক করুন)।
Tips
  • Category ও User ফিল্ডে শুধু টাইপ করে না, ড্রপডাউনের আইটেমে ক্লিক করে সিলেক্ট করুন— এতে প্রয়োজনীয় আইডি/ভ্যালু সঠিকভাবে সেট হয়।
  • User Name লিস্ট আপনার ডিপার্টমেন্ট (যা .departmentName থেকে নেয়) অনুযায়ী ফিল্টার হয়।
  • Using starting Date স্থানীয় টাইমজোন অনুযায়ী দিন; পুরোনো ডিভাইস মাইগ্রেশনে বাস্তবসম্মত তারিখ দিন।
  • ডায়নামিক ফিল্ডে ফাইল/চেকবক্স/রেডিও থাকলে প্রয়োজনমতো নির্বাচন করুন; কিছু ফিল্ড (যেমন customDropDownList) অ্যাসিঙ্কে লোড হয়—লোড শেষ হতে একটু অপেক্ষা করুন।
  • বারবার Save চাপবেন না—ডুপ্লিকেট এন্ট্রি হতে পারে।
  • তালিকায় যুক্ত হওয়ার পর চাইলে Components 👁 দিয়ে কম্পোনেন্ট দেখুন, Device User 👁 দিয়ে ইউজার-ইতিহাস দেখুন, এবং পরে Service/✔ Distribute অ্যাকশন ব্যবহার করুন।
  • অনেক ডেটা হলে বাম পাশের Page Size সিলেক্টর দিয়ে প্রতি পেজে আইটেম সংখ্যা নিয়ন্ত্রণ করুন।

Edit Old Device

Steps
  1. Device List থেকে সার্চ/সোর্ট করে ডিভাইসটি খুঁজে নিন।
  2. Edit আইকনে ক্লিক করুন (Action কলাম)।
  3. Edit Device Information মডাল ওপেন হবে; Category ফিল্ডটি read-only থাকবে।
  4. Universal fields (কনফিগারেশনের উপর ভিত্তি করে) অটো-রেন্ডার হবে; যদি customDropDownList থাকে, তা অ্যাসিঙ্কে লোড হবে।
  5. Individual fields ডিভাইসের ক্যাটাগরি অনুযায়ী দেখাবে।
  6. সব ফিল্ডের আগের মানগুলো স্বয়ংক্রিয়ভাবে পূরণ হবে (একটু সময় দিন—~১ সেকেন্ড); প্রয়োজনমতো আপডেট করুন।
  7. Save বাটনে ক্লিক করে পরিবর্তন সংরক্ষণ করুন; সাকসেস বার্তার পর তালিকায় আপডেট রিফ্রেশ হয়ে এসেছে কি না যাচাই করুন।
Tips
  • Category ইচ্ছাকৃতভাবে বদলানো যাবে না (read-only)। ক্যাটাগরি বদলাতে আলাদা প্রক্রিয়া/পারমিশন লাগতে পারে।
  • অটো-ফিল মূলত <input name="columnName"> টার্গেট করে; checkbox/radio/file টাইপ হলে প্রয়োজনে ম্যানুয়ালি সেট করুন।
  • customDropDownList লোড শেষ হওয়ার আগে Save দেবেন না—লিস্ট দেখা না গেলে কয়েক সেকেন্ড অপেক্ষা করুন।
  • একই রেকর্ডে বারবার Save চাপবেন না—ডুপ্লিকেট/রেস কন্ডিশন এড়াতে একবার ক্লিকই যথেষ্ট।
  • ফিল্ড না দেখালে/ভ্যালু না বসলে পেজটি রিফ্রেশ করে আবার চেষ্টা করুন বা কনসোলে এরর চেক করুন (যেমন: deviceId অনুপস্থিত)।
  • আপডেটের পর দ্রুত যাচাই করতে সার্চ বক্স ও কলাম Sort (⇅) ব্যবহার করুন।

Add Service Request

Steps
  1. Device List থেকে সার্চ/সোর্ট করে টার্গেট ডিভাইসটি খুঁজে নিন।
  2. Action কলামের Service বাটনে ক্লিক করুন — Service Request মডাল ওপেন হবে।
  3. Problems সেকশনে প্রথম ইনপুটটি অটো-ক্রিয়েট হবে। সমস্যার নাম লিখুন।
  4. আরও সমস্যা যোগ করতে Add Problem চাপুন বা ইনপুটে টাইপ করে Enter প্রেস করুন। ভুল হলে ডানপাশের X দিয়ে রিমুভ করুন।
  5. Comment বক্সে অতিরিক্ত তথ্য/বিবরণ দিন (ঐচ্ছিক কিন্তু সুপারিশকৃত)।
  6. সব ঠিক থাকলে Save ক্লিক করুন — সিস্টেম addTableInformationOfService(deviceId, comment, categoryName) কল করে রিকোয়েস্ট তৈরি করবে।
  7. তৈরির পর Service Request List এ নতুন রেকর্ড এসেছে কি না যাচাই করুন; প্রয়োজনে Tracking → View থেকে প্রগ্রেস দেখুন।
Tips
  • প্রতিটি সমস্যার জন্য সংক্ষিপ্ত কিন্তু পরিষ্কার নাম ব্যবহার করুন (যেমন: “No Power”, “Overheating”, “LAN Port Dead”).
  • কমপক্ষে একটি সমস্যা রাখুন; খালি রেখে Save দেবেন না।
  • Add Problem দ্রুত করতে ইনপুটে Enter প্রেস করা যায়; অপ্রয়োজনীয় এন্ট্রি X দিয়ে সরিয়ে দিন।
  • Save একবারই ক্লিক করুন — বারবার ক্লিক করলে ডুপ্লিকেট/রেস কন্ডিশন হতে পারে।
  • রিকোয়েস্ট কোন ডিভাইসের জন্য তা সার্ভারে data-device-id থেকে সেট হয়—ভুল ডিভাইসে Service চাপবেন না।
  • বড় তালিকায় দ্রুত খুঁজতে Search বক্স ও কলাম ⇅ সোর্ট ব্যবহার করুন।

Delete Old Device

Steps
  1. User List থেকে ইউজার খুঁজুন
  2. Delete আইকনে ক্লিক করুন
  3. Confirmation মডালে Yes চাপুন
  4. ইউজার তালিকা থেকে মুছে গেছে কিনা যাচাই করুন
Tips
  • ডিলিট করার আগে ডাটা ব্যাকআপ প্রয়োজন কিনা ভেবে নিন
  • ভুল ইউজার ডিলিট হলে তা পুনরুদ্ধার করা যাবে না
  • Admin রোলের ইউজার ডিলিট করতে বিশেষ অনুমতি লাগতে পারে

✔ Distribute Device

Steps
  1. Device List থেকে টার্গেট ডিভাইসটি খুঁজে নিন (সার্চ/সোর্ট ব্যবহার করুন)।
  2. ✔ Distribute বাটনে ক্লিক করুন — “Distribute device to a user” মডাল ওপেন হবে।
  3. User Name ইনপুটে ক্লিক করুন → ড্রপডাউন থেকে সঠিক ইউজার নির্বাচন করুন (টাইপ করে ফিল্টার করা যায়; তালিকা আপনার department অনুযায়ী আসে)।
  4. Using starting Date এ বরাদ্দের শুরু তারিখ–সময় দিন (datetime-local)।
  5. Save ক্লিক করুন → সিস্টেম distributeDeviceDirect(deviceId) কল করে বরাদ্দ সম্পন্ন করবে।
  6. তালিকার Device User কলামে নির্বাচিত ইউজার দেখা যাচ্ছে কি না যাচাই করুন; প্রয়োজন হলে 👁 আইকনে ইতিহাস দেখুন।
Tips
  • User Name ফিল্ডে শুধু টাইপ করলেই হবে না—ড্রপডাউন থেকে আইটেমে ক্লিক করে সিলেক্ট করুন, নইলে ইউজারের আইডি সেট নাও হতে পারে।
  • ইউজার তালিকা আপনার ব্রাঞ্চ/ডিপার্টমেন্ট অনুযায়ী ফিল্টারড; ইউজার না পেলে তার ব্রাঞ্চ চেক করুন।
  • Date–time বাধ্যতামূলক; স্থানীয় টাইমজোন অনুযায়ী দিন।
  • একবারই Save চাপুন—ডাবল-ক্লিক করলে ডুপ্লিকেট/রেস কন্ডিশন হতে পারে।
  • আগে থেকেই ডিভাইস বরাদ্দ থাকলে নতুন বরাদ্দে পুরনোটি ওভাররাইড/ক্লোজ হতে পারে—নীতিমালা মেনে কাজ করুন।
  • ডিস্ট্রিবিউশনের পর দ্রুত যাচাইয়ের জন্য Device User কলাম ও 👁 ইতিহাস দেখুন।
