Overview

এই পেজ থেকে আপনি ডিভাইসের জন্য রিকোয়েস্ট তৈরি, সম্পাদনা, ডিলিট এবং কাস্টমারকেয়ার থেকে পাঠানো ডিভাইস রিসিভ করতে পারবেন। দ্রুত খোঁজার জন্য Search/Sort ও Page Size সিলেক্টর রয়েছে।

Quick actions
  • Add Device Request — Category সিলেক্ট করে requestColumns অনুযায়ী ফর্ম পূরণ করুন, এরপর Save।
  • Edit — ✏ (Action) থেকে রিকোয়েস্ট আপডেট করুন; ফিল্ডগুলো অটো-ফিল হয়ে আসবে।
  • Delete — 🗑 (Action) থেকে কনফার্ম করে রিকোয়েস্ট মুছুন।
  • Receive Device — কাস্টমারকেয়ার পাঠানো ডিভাইস থাকা রিকোয়েস্টে ✔ চাপুন, তালিকা থেকে একটি ডিভাইস সিলেক্ট করে Accept করুন।
Find & Track
  • Search বক্সে টাইপ করে দ্রুত খুঁজুন; কলাম হেডারের ⇅ দিয়ে সোর্ট করুন।
  • Page Size দিয়ে প্রতিপৃষ্ঠায় আইটেম সংখ্যা ঠিক করুন।
  • Tracking → View ক্লিক করে রিকোয়েস্টের ধাপ/প্রগ্রেস দেখুন।
Status & rules
  • Request Status in COO: Pending / Accepted / Denied
  • Device Received Status: Pending / Received
  • Accepted/Denied হলে সাধারণত Edit/Delete নিষ্ক্রিয়/লুকানো থাকে।
  • Denied হলে স্ট্যাটাসে ক্লিক করে Reject Cause দেখা যায়।
Notes
  • Mandatory (Add): Category + প্রাসঙ্গিক ডায়নামিক ফিল্ডসমূহ (requestColumns).
  • ড্রপডাউন ইনপুটে শুধু টাইপ নয়—লিস্ট থেকে ক্লিক করে সিলেক্ট করুন, নইলে মান সঠিকভাবে সেট নাও হতে পারে।
  • একই রেকর্ডে বারবার Save/Accept/Delete চাপবেন না—একবার ক্লিকই যথেষ্ট।

Add Device Request

ভিডিও: Add Device Request ডেমো Download
Steps
  1. উপরে Add Device Request বাটনে ক্লিক করুন — Add Request Information মডাল ওপেন হবে।
  2. Category Name ইনপুটে ক্লিক করে ড্রপডাউন থেকে সঠিক ক্যাটাগরি সিলেক্ট করুন (লিস্ট আসে সিস্টেমের categories থেকে; টাইপ করে ফিল্টার করা যায়)।
  3. ক্যাটাগরি সিলেক্ট করার পর requestColumns থেকে ডায়নামিক ফিল্ডগুলো (যেমন: text, number, date, time, datetime-local, file, checkbox, radio, textarea ইত্যাদি) Request সেকশনে দেখা যাবে—প্রয়োজন অনুযায়ী পূরণ করুন।
  4. সব ঠিক থাকলে Save ক্লিক করুন—সিস্টেম saveTableInformationOfRequest() কল করে রিকোয়েস্ট সংরক্ষণ করবে।
  5. সাকসেসের পর মূল তালিকায় রেকর্ড এসেছে কি না যাচাই করুন; প্রয়োজন হলে সার্চ/সোর্ট ব্যবহার করুন।
  6. রিকোয়েস্টের অগ্রগতি দেখতে Tracking কলামের View–এ ক্লিক করুন।
Tips
  • Category শুধু টাইপ করলে হবে না—ড্রপডাউন থেকে আইটেমে ক্লিক করে সিলেক্ট করুন; তবেই মান সঠিকভাবে সেট হবে (selectionAndInputDevice() হ্যান্ডলার)।
  • textarea ফিল্ডে রিকোয়েস্টের যুক্তি/ডিটেইলস স্পষ্টভাবে লিখুন—রিভিউতে সহায়তা করবে।
  • ফাইল/চেকবক্স/রেডিও টাইপ ফিল্ডে সঠিক নির্বাচন/ফাইল দিন; প্রয়োজনে ফাইল সাইজ/ফরম্যাট নীতিমালা অনুসরণ করুন।
  • একই রেকর্ডে বারবার Save চাপবেন না—ডুপ্লিকেট/রেস কন্ডিশন এড়াতে একবার ক্লিকই যথেষ্ট।
  • Request Status in COO এবং Device Received Status কলাম থেকে প্রগ্রেস দেখুন; Denied হলে স্ট্যাটাসে ক্লিক করে Reject Cause দেখুন।
  • অনেক ডেটা হলে বাম পাশের Page Size সিলেক্টর ও ডান পাশের Search বক্স ব্যবহার করুন।
  • রিকোয়েস্ট Accepted/Denied হলে Action–এর Edit/Delete বাটন লুকানো থাকতে পারে—নীতিমালা অনুযায়ী লকড স্ট্যাটাস।

Edit Device Request

ভিডিও: Edit Device Request ডেমো Download
Steps
  1. Device Request তালিকা থেকে সার্চ/সোর্ট করে রিকোয়েস্টটি খুঁজে নিন।
  2. Edit আইকনে ক্লিক করুন (Action কলাম)।
  3. Edit Request Information মডাল ওপেন হবে; Category Name ফিল্ডে বর্তমান ক্যাটাগরি প্রি-ফিলড থাকবে। প্রয়োজন হলে ড্রপডাউন থেকে নতুন ক্যাটাগরি নির্বাচন করুন (হ্যান্ডলার: selectionAndInputDeviceEdit2()).
  4. নিচের Request সেকশনে requestColumns অনুসারে ডায়নামিক ফিল্ডগুলো (text, number, date, time, datetime-local, file, checkbox, radio, textarea ইত্যাদি) রেন্ডার হবে।
  5. সিস্টেম columnValue(requestIdData, ...) দিয়ে আগের মানগুলো স্বয়ংক্রিয়ভাবে বসাবে—একটু সময় দিন, তারপর প্রয়োজনমতো আপডেট করুন।
  6. Save চাপুন—সিস্টেম EditTableInformationOfRequest(requestIdData) কল করে পরিবর্তন সংরক্ষণ করবে।
  7. সাকসেসের পর তালিকায় আপডেট দেখা যাচ্ছে কি না যাচাই করুন; প্রয়োজনে Tracking কলামের View দিয়ে প্রগ্রেস দেখুন।
Tips
  • Accepted/Denied স্ট্যাটাসে Edit/Delete বাটন লুকানো/লক থাকতে পারে—নীতিমালা অনুসারে পরিবর্তন করা যায় না।
  • ক্যাটাগরি বদলালে সংশ্লিষ্ট ফিল্ড/ভ্যালিডেশন বদলাতে পারে—সেভের আগে সব প্রয়োজনীয় ফিল্ড পূরণ করুন।
  • ড্রপডাউনভিত্তিক ইনপুটে শুধু টাইপ নয়—লিস্টের আইটেমে ক্লিক করে সিলেক্ট করুন, নইলে মান সঠিকভাবে সেট নাও হতে পারে।
  • file / checkbox / radio টাইপ সাধারণত অটো-ফিল হয় না—ম্যানুয়ালি সেট করুন। textarea তে সাধারণ টেক্সট ব্যবহার করুন (plain-textarea)।
  • একই রেকর্ডে বারবার Save চাপবেন না—ডুপ্লিকেট/রেস কন্ডিশন এড়াতে একবার ক্লিকই যথেষ্ট।
  • অগ্রগতি/কারণ জানতে তালিকার Request Status in COO ও Device Received Status দেখুন; Denied হলে স্ট্যাটাসে ক্লিক করে Reject Cause পড়ুন।

Delete Device Request

ভিডিও: Delete Device Request ডেমো Download
Steps
  1. Device Request তালিকা থেকে সার্চ/সোর্ট করে রিকোয়েস্টটি খুঁজে নিন।
  2. Delete আইকনে ক্লিক করুন (Action কলাম)।
  3. কনফার্মেশন ডায়ালগে Delete/Yes চাপুন।
  4. সাকসেস বার্তার পর তালিকায় রিকোয়েস্টটি আর আছে কি না যাচাই করুন; না থাকলে ডিলিট সফল হয়েছে।
Tips
  • Accepted বা Denied স্ট্যাটাসে সাধারণত Edit/Delete বাটন লুকানো থাকে—এ সময় ডিলিট করা যায় না।
  • ডিলিট করার আগে Request Status in COO, Device Received Status এবং Tracking → View দেখে নিন—প্রসেসে থাকলে ডিলিট না করাই ভালো।
  • ডিলিট permanent—পুনরুদ্ধার সম্ভব নয়; প্রয়োজন হলে আগে তথ্য ব্যাকআপ নিন।
  • Denied হলে স্ট্যাটাসে ক্লিক করে Reject Cause দেখা যায়—ডিলিট না করে কারণ বুঝে পুনরায় সাবমিট করার সিদ্ধান্ত নিন।
  • একবারই Delete চাপুন—ডাবল-ক্লিক করলে অপ্রত্যাশিত আচরণ হতে পারে।
  • অনেক রেকর্ড হলে Page Size সিলেক্টর ও Search বক্স ব্যবহার করে দ্রুত খুঁজে নিন।

✔ Receive Device

ভিডিও: Receive Device ডেমো Download
Steps
  1. Device Request তালিকায় যে রিকোয়েস্টের Device Received Status = Pending, সেটি সার্চ/সোর্ট করে খুঁজে নিন।
  2. Action কলামের Receive বাটনে ক্লিক করুন—Device Information মডাল ওপেন হবে।
  3. টেবিলে ডিভাইসের ডিটেইলস যাচাই করুন (SN, Category, ডায়নামিক কলাম, Description)।
  4. Action কলামের চেকবক্সে ক্লিক করে শুধু একটি ডিভাইস সিলেক্ট করুন।
  5. Accept বাটনে ক্লিক করুন → কনফার্ম ডায়ালগে OK চাপুন।
  6. মডাল ক্লোজ হলে তালিকায় স্ট্যাটাস আপডেট হয়েছে কি না দেখুন (প্রয়োজনে Tracking → View থেকে ডিটেইলস দেখুন)।
Tips
  • একাধিক বা শূন্য সিলেকশন করলে সিস্টেম সতর্ক করবে—ঠিকভাবে কাজ করতে একটি মাত্র ডিভাইস সিলেক্ট করুন।
  • লিস্ট না এলে বা খালি থাকলে সিস্টেম “No data found to display in the modal.” দেখাতে পারে—ক্যাটাগরি/ডিভাইস আইডি মিলছে কি না যাচাই করুন।
  • Accept ক্লিকের পর ডাবল-ক্লিক করবেন না—একবার ক্লিকই যথেষ্ট (ফাংশন: acceptDeliveryDevice(requestId, selectedRows))।
  • চেকবক্স থাকা কলামে ডিভাইসের hidden id (২য় কলাম) ব্যবহৃত হয়—কলাম অর্ডার না বদলানো উত্তম।
  • স্ট্যাটাস আপডেট না দেখালে পেজ রিফ্রেশ করুন বা Tracking থেকে প্রসেস স্টেপ যাচাই করুন।
