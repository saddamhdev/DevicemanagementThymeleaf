Overview

এই পেজ থেকে আপনি ইউজার যোগ, সম্পাদনা ও ডিলিট করতে পারবেন। দ্রুত খোঁজার জন্য Search users… ও কলাম Sort (⇅) রয়েছে। তালিকায় শুধুমাত্র আপনার ডিপার্টমেন্ট/ব্রাঞ্চের ইউজার দেখাবে।

Quick actions
  • Add User — User Name, User ID, Designation, Join Date দিয়ে নতুন ইউজার তৈরি করুন, তারপর Save।
  • Edit — Action কলামের ✏ আইকনে ক্লিক করে তথ্য আপডেট করুন; Designation DB থেকে লোড হয়।
  • Delete — 🗑 আইকনে ক্লিক; কনফার্মেশনের পর ইউজার রিমুভ হবে।
Find & review
  • Search users… বক্সে টাইপ করে দ্রুত খুঁজুন।
  • কলাম হেডারের ⇅ এ ক্লিক করে User Name / User ID / Join Date ইত্যাদি অনুযায়ী সোর্ট করুন।
  • তৈরির পর তালিকায় এন্ট্রি/আপডেট হয়েছে কি না সাথে সাথেই যাচাই করুন।
Mandatory (Add): User Name, User ID, Designation, Join Date • Note: Designation তালিকা সিস্টেমে প্রি-কনফিগার্ড এবং এডিটের সময় DB থেকে লোড হয় • Tip: User ID ইউনিক রাখুন; বারবার Save চাপবেন না।

Add User

ভিডিও: Add User ডেমো Download
Steps
  1. উপরে Add User বাটনে ক্লিক করে ফর্মটি ওপেন করুন।
  2. User Name ও User ID লিখুন।
  3. Designation ড্রপডাউন থেকে সঠিক পদবি নির্বাচন করুন।
  4. User Join Date (তারিখ) সিলেক্ট করুন।
  5. Save বাটনে ক্লিক করে রেকর্ড তৈরি করুন।
  6. নিচের তালিকায় নতুন ইউজার যুক্ত হয়েছে কিনা যাচাই করুন। প্রয়োজনে উপরের ডান পাশে থাকা Search users… বক্সে খুঁজে দেখুন।
  7. ফর্ম বন্ধ করতে Close বাটন ব্যবহার করুন।
Tips
  • User ID ইউনিক রাখুন (ডুপ্লিকেট হলে পরে লগইন/সনাক্তকরণে সমস্যা হবে)।
  • Designation তালিকা সিস্টেমে প্রি-কনফিগার্ড—ভুল পজিশন সিলেক্ট করলে পারমিশন/রোল মিসম্যাচ হতে পারে।
  • টেবিলের শিরোনামে থাকা ⇅ আইকনে ক্লিক করে কলামভিত্তিক সাজাতে পারেন (User Name, User ID, Join Date ইত্যাদি)।
  • উপরে ডানদিকে থাকা সার্চ বক্স (Search users…) লাইভ ফিল্টার করে; দ্রুত রেকর্ড খুঁজে পেতে এটি ব্যবহার করুন।
  • তথ্য বদলাতে Edit () এবং মুছতে Delete () ব্যবহার করুন।
  • এই তালিকায় শুধু আপনার ডিপার্টমেন্ট/ব্রাঞ্চের ইউজারই দেখাবে (সিস্টেমে ব্রাঞ্চ ফিল্টার প্রযোজ্য)।

Edit User

ভিডিও: Edit User ডেমো Download
Steps
  1. User List থেকে সার্চ/সোর্ট করে ইউজার নির্বাচন করুন।
  2. Edit আইকনে ক্লিক করুন (Action কলাম)।
  3. Edit User Information মডাল ওপেন হবে; User Name, User Id, Join Date আগের ভ্যালু সহ দেখা যাবে।
  4. User Designation ড্রপডাউন প্রথমে Loading… দেখাবে—ডাটাবেস থেকে তালিকা লোড হলে সঠিক পদবি সিলেক্ট করুন (আগেরটি প্রি-সিলেক্টেড হতে পারে)।
  5. প্রয়োজনীয় ফিল্ডগুলো আপডেট করুন।
  6. Save বাটনে ক্লিক করুন।
  7. সাকসেস মেসেজের পর তালিকায় ডেটা আপডেট হয়েছে কি না যাচাই করুন।
Tips
  • Designation তালিকা ডাটাবেস থেকে আসে; দীর্ঘ সময় Loading… থাকলে রিফ্রেশ করে আবার চেষ্টা করুন।
  • No designations found দেখালে আগে সিস্টেমে Designation যোগ হয়েছে কিনা যাচাই করুন।
  • User ID অকারণে পরিবর্তন করবেন না—লগইন/পারমিশনে প্রভাব পড়তে পারে।
  • Join Date ইনপুটে YYYY-MM-DD ফরম্যাট লাগে; টেবিল থেকে অটো-ফরম্যাট না হলে ম্যানুয়ালি দিন।
  • একই রেকর্ডে বারবার Save না চাপুন; একবার ক্লিক করলেই যথেষ্ট।
  • দ্রুত খুঁজতে সার্চ বক্স ও কলাম Sort (⇅) ব্যবহার করুন।

Delete User

ভিডিও: Delete User ডেমো Download
Steps
  1. User List থেকে ইউজার খুঁজুন
  2. Delete আইকনে ক্লিক করুন
  3. Confirmation মডালে Yes চাপুন
  4. ইউজার তালিকা থেকে মুছে গেছে কিনা যাচাই করুন
Tips
  • ডিলিট করার আগে ডাটা ব্যাকআপ প্রয়োজন কিনা ভেবে নিন
  • ভুল ইউজার ডিলিট হলে তা পুনরুদ্ধার করা যাবে না
  • Admin রোলের ইউজার ডিলিট করতে বিশেষ অনুমতি লাগতে পারে
